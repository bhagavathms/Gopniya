# Gopniya (गोपनीय) 🛡️
> A high-throughput, low-latency enterprise AI Gateway and Security Proxy.

---

## 📌 Project Status
🚧 **Under Active Development** (Building milestone by milestone)

---

## 🛠️ Planned Tech Stack
* **Core:** Python, FastAPI, Pydantic, `httpx`
* **State & Caching:** Redis (Token-bucket rate limiting & caching)
* **Messaging:** Apache Kafka (Audit logs & telemetry)
* **Database:** PostgreSQL, SQLAlchemy (Async)
* **Containerization:** Docker & Docker Compose
